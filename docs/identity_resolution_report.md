# Identity resolution report

Generated by `python -m pipelines.identity_resolution.run`. Do not edit by hand.

Auto-match threshold **0.90**, target set **50,149** Transfermarkt identities.

Resolution never matches on name alone. A name is one signal alongside date of birth, nationality, club and position, and on its own it cannot reach the threshold whatever its similarity.


## Why two runs

A wrong match is worse than no match: an unmatched player is visibly missing, while a wrongly matched one silently attaches somebody else's statistics to a real person's profile. The two runs below measure the two failure modes separately.

## Run 2 — perturbed shadow against Transfermarkt

Real identities are copied and degraded the way a second provider would differ: name order swapped, middle names dropped, playing name instead of registered name, occasional typos, and missing birth date, nationality or club. Ground truth is known by construction.

Some records are unresolvable by design — a surname alone with no birth date cannot be pinned to one person — so recall below 100% is the correct outcome, not a defect. Those records belong in manual review.
